# 🧮 Calculator Web App

A simple calculator built with Python, originally developed as a desktop app using **Tkinter**, and later ported to a web-based version using **Streamlit** for easy public access — no installation required.

🔗 **Live Demo:** [amiraziz1221-calculator-app-streamlit-app-wokuma.streamlit.app](https://amiraziz1221-calculator-app-streamlit-app-wokuma.streamlit.app/)

## ✨ Features

- Basic arithmetic operations: addition, subtraction, multiplication, division
- Clear (C) button to reset the display
- Division-by-zero handling with an "Error" message
- Clean green-on-black UI inspired by the original Tkinter design
- Fully responsive and accessible from any browser — desktop or mobile

---

## 🛠️ Tech Stack

- **Python 3**
- **Streamlit** — web app framework
- Originally prototyped with **Tkinter** (desktop GUI)

---

## 🚀 Run Locally

Clone the repo and install dependencies:

```bash
git clone https://github.com/AmirAziz1221/calculator-app.git
cd calculator-app
pip install -r requirements.txt
```

Run the app:

```bash
streamlit run streamlit_app.py
```

The app will open automatically in your browser at `http://localhost:8501`.
